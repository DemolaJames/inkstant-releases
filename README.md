# Inkstant by me360

**Sign PDFs in seconds. Nothing leaves your computer.**

Open a PDF, add your signature, initials, name and date, and save a signed copy, all on your own
computer. No account, no uploads, works offline. Free.

## Download

Get the latest version from **[Releases](https://github.com/DemolaJames/inkstant-releases/releases/latest)**:

| | File | First launch |
|---|---|---|
| **Windows 10 / 11** | `Inkstant-Setup-<version>.exe` | If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**. |
| **macOS** | `Inkstant-<version>-macos.dmg` | Drag Inkstant to Applications, then **right-click → Open** the first time. |

Those warnings appear because Inkstant is a new, independent app that isn't code-signed yet. It's safe.
